# Kinbox docs

Central de ajuda e referência da API da Kinbox, publicadas com o [Mintlify](https://mintlify.com) a partir da branch `main`.

Este repositório é mantido por agentes de IA, sem revisão humana: as regras estão em [`AGENTS.md`](AGENTS.md) e [`guia-de-escrita.md`](guia-de-escrita.md), e as checagens do CI (`bun scripts/checar.ts`) bloqueiam o merge quando algo não passa.

```bash
npm i -g mint@4.2.410
mint dev               # prévia local em http://localhost:3000
bun scripts/checar.ts  # todas as checagens do CI
```
